# PSVS Operations

This folder describes the main operations of the Polar Vault Seed Storage System.

## 1. Deposit
Accept a seed box from a registered depositor and store it in an available chamber.

## 2. Withdraw
Release a stored box according to ownership, annual quota, and authorization rules.

## 3. Redeposit
Accept a previously withdrawn box only after re-inspection.

## 4. MoveBox
Move a box from one chamber to another while respecting capacity and temperature constraints.

## 5. DeclareEmergency
Record an emergency and apply the authorized emergency-release procedure.

## 6. StartMaintenance
Place a chamber into maintenance mode under the approved maintenance rules.

## 7. QueryChamberLoad
Return the number of boxes currently stored in a chamber.
