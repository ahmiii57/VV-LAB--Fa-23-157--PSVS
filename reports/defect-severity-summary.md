# PSVS Defect Severity Summary

## 1. Severity Levels

| Severity | Description |
|---|---|
| Critical | Defect may cause serious system failure or security issue. |
| High | Defect may affect an important system function. |
| Medium | Defect may create confusion or incorrect behavior. |
| Low | Defect has a minor impact on the system. |
